# Admin Frontend Portal Setup

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure `.env`:
   ```bash
   cp .env.example .env
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
   Admin portal runs on `http://localhost:5174`.

## Features
- Superadmin authentication.
- Multi-tenant organization creation & credential generation.
- Organization freezing & unfreezing.
- System metrics and tenant drill-down.
