Executive Summary

This document details the comprehensive report generation system added to the Spren Pharmacy POS platform. The system enables pharmacists, store managers, and business owners to generate, preview, and download actionable business intelligence reports across inventory, financial, customer, and supplier domains — all directly from the web dashboard with zero external tooling required.

Reports are generated entirely on the client side using live database data, ensuring real-time accuracy without requiring additional server infrastructure. Each report includes automated KPI summary metrics, date-range filtering, and customizable field selections. All exports are branded with the Spren Pharmacy identity for a professional, print-ready output.

Category 1 — Inventory & Stock Reports

These reports provide granular visibility into current stock levels, product catalog health, expiry risk, and inventory valuation across the pharmacy's entire product database.

📦
1. Stock Summary Report
Inventory

A complete snapshot of the pharmacy's entire product catalog. Lists every registered product with its batch/SKU code, category classification, HSN code for GST compliance, current quantity on hand, unit selling price, computed stock value (quantity × price), and real-time availability status (In Stock / Low Stock / Out of Stock).

5. GST & Tax Breakdown Report
Financial

Designed for GST filing and tax compliance. Breaks down every invoice into its taxable component and applicable GST at the standard 12% pharmaceutical rate — split into CGST (6%) and SGST (6%). Aggregates total taxable sales, total GST collected, and gross invoice value across the selected date period.

Access Points

The report system can be accessed from three locations within the Spren POS application:

📊 Stock Manager Dashboard

Click "AI Analytics Report" in the Quick Actions panel to open the full report generator modal with all 9 report types, date filtering, and format selection.

Navigation → Dashboard → AI Analytics Report

📦 Inventory Page

Click the "Export" button in the page header to open the Reports & Export Center with dual tabs — Full Report Generator and Quick Inventory Export.

Navigation → Inventory → Export Button

➕ Add Product Modal

Click the expandable "Quick Report Downloads" section below the AI Import and Manual Register options for instant report generation.

Any "Add Product" Button → Quick Report Downloads

🔗 Technology Stack

Built with jsPDF + jspdf-autotable for PDF generation, SheetJS (xlsx) for Excel exports, and native Blob API for CSV. Zero server-side dependencies.
